## How I approach client work

1. **Diagnose before changing things** — separate tracking, platform, storefront, feed, and campaign problems.
2. **Make the smallest reliable fix** — avoid unnecessary changes that create new risk.
3. **Validate end-to-end** — compare browser events, platform diagnostics, API responses, and store data.
4. **Document the result** — explain what was wrong, what changed, and how to verify it later.
5. **Protect production systems** — no secrets in source, no client data in demos, and rollback paths where needed.
