## How I approach client work

1. **Diagnose before changing things** — separate storefront, tracking, feed, platform and campaign-side problems.
2. **Make the smallest reliable fix** — avoid unnecessary changes that create new production risk.
3. **Validate end-to-end** — compare browser events, platform diagnostics, API responses and store data.
4. **Leave a clear verification path** — document what was wrong, what changed and how to test it later.
